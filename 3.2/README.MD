# Программа IPv4

## Описание
Программа написана на языке C. Она имитирует отправку пакетов по сети и проверяет, принадлежат ли IP-адреса одной подсети.

## Как работает программа
1. Пользователь вводит IP-адрес шлюза.
2. Вводит маску подсети.
3. Указывает количество пакетов.
4. Программа генерирует случайные IP-адреса.
5. Проверяет, находятся ли они в одной подсети со шлюзом.
6. Выводит результат и общую статистику.

## Используемые библиотеки
- `stdio.h` — ввод и вывод.
- `stdlib.h` — случайные числа.
- `time.h` — время.
- `stdint.h` — работа с 32-битными числами.

## Компиляция GCC

```bash
gcc main.c -o ipv4
```

## Запуск программы

Linux:
```bash
./ipv4
```


## Пример ввода

```text
IP шлюза: 192.168.1.1
Маска: 255.255.255.0
Количество пакетов: 100
```

## Результат
В конце программа показывает:
- Количество пакетов для своей подсети.
- Количество пакетов для других сетей.
- Процент пакетов в каждой категории.
