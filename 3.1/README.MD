# Программа для работы с правами доступа

Программа написана на языке C для Linux.

Она выполняет три функции:

**1. Перевод прав доступа**

Пользователь вводит права, например `755` или `rwxr-xr-x`. Программа показывает их в цифровом, буквенном и битовом форматах.

**2. Получение прав файла**

В проекте есть файл `text.txt`, с помощью которого можно проверить права доступа. Пользователь вводит его имя, а программа с помощью `stat()` получает права и показывает их в трёх форматах.

**3. Изменение прав доступа**

Пользователь вводит начальные права и команды, например `u+rw`, `g-w`, `o+x`. Программа пересчитывает права после каждой команды.

Все изменения выполняются только внутри программы. Реальные права файлов не меняются.

## Запуск программы

Файлы `Lab_3_1.c` и `text.txt` должны находиться в одной папке.

**1. Компиляция:**

```bash
gcc Lab_3_1.c -o program
```

**2. Запуск:**

```bash
./program
```

**3. Проверка прав файла:**

В главном меню выберите пункт `2` и введите:

```text
text.txt
```

Программа покажет текущие права файла в трёх форматах.
